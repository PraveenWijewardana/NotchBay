# 🚀 NotchBay v1.0.0 — Official Release

Welcome to the first official release of **NotchBay**!  
NotchBay transforms the camera notch on Apple Silicon MacBooks (and external displays) into a powerful, interactive Dynamic Island command center.

---

## 📥 Download

- **macOS Universal Disk Image**: [**`NotchBay.dmg`**](https://github.com/PraveenWijewardana/NotchBay/raw/main/NotchBay.dmg) (`4.1 MB`)
- **Compatibility**: macOS 14.0 (Sonoma) or macOS 15+ (Sequoia) — Apple Silicon (M1/M2/M3/M4) & Intel.

---

## 🌟 What's New in v1.0.0

### 🖥️ Hardware & Network Telemetry
- **Low-Overhead Mach Kernel Telemetry**: Live CPU and Apple Silicon Metal GPU loads with real-time vector sparkline history.
- **Memory & Storage**: Detailed breakdown of active, wired, and compressed memory with swap pressure notifications. Instantaneous disk read/write throughput.
- **Network Bandwidth**: Live download/upload speed gauges and dual-line Bezier waveform charts.
- **Power & Thermals**: Battery cycle stats, live wattage draw, charging status, and thermal throttling states.

### 🎵 Media Controller & Synchronized Lyrics
- **Apple Music & Spotify Integration**: Seamless bidirectional AppleScript control with live album artwork and artist metadata.
- **Synchronized Live Lyrics**: Dynamic scrolling lyrics viewer with active lyric line magnification, glowing neon aura, and progress scrubbing.
- **Audio Equalizer**: Multi-frequency animated spectrum visualizer synced with playing audio.
- **Precision Volume Slider**: Smooth slider with non-wrapping single-line percentage indicator (`100%`).

### 📁 Notch Drop Shelf
- **Frictionless File Holding**: Drag and drop documents, screenshots, links, and code snippets straight into the notch.
- **Lightweight Thumbnails**: Downsampled thumbnail previews maintaining an ultra-lean memory footprint (<25 MB).
- **One-Click Drag-Out**: Instantly drag stashed files into Slack, Mail, Xcode, or Finder.

### 🤖 AI Code Agent Companion
- **Real-Time Agent Auto-Detection**: Actively monitors background coding agents:
  - Claude Code (`claude`)
  - Cursor Composer (`cursor`)
  - GitHub Copilot (`copilot`)
  - Codex (`codex`)
  - Aider (`aider`)
- **Telemetry & Costs**: Displays live task status, tool calls, execution elapsed time, and token/cost estimations directly in the notch.

### ⏱️ Focus Timers & Mechanical Ruler Dial
- **Presets & Pomodoro**: One-tap presets (`5m`, `10m`, `25m`) and automated Pomodoro focus/break cycles.
- **Interactive Ruler Slider**: Scrub visually across calibrated tick marks with dynamic completion estimations and mechanical click sounds.
- **Stopwatch**: High-precision stopwatch with lap split records.

### 🌦️ Atmospheric Weather Dashboard
- **Live Particle Simulation**: Dynamic particle effects matching real conditions (rain, snow, lightning, solar flares, and twinkling stars).
- **Hourly Forecast**: 24-hour temperature trends, feels-like temperature, humidity, UV index, and wind velocity.

### 🔔 System HUD Overlays
- **Smooth Notch Popups**: Unobtrusive HUD indicators emerging from behind the camera bezel:
  - System Volume & Display Brightness sliders
  - Caps Lock engagement indicator
  - AirDrop transfer progress & file received notification
  - Incoming call banners for FaceTime, WhatsApp, and Phone

### 🔒 Keep Open / Pin Mode
- Integrated pin button on every tab to lock the island expanded while multitasking across multiple desktop applications.

### ⚙️ Polished Settings Window
- **Frosted Translucent Header**: Apple `.ultraThinMaterial` frosted glass top bar with custom opacity.
- **Official App Icon**: Real high-resolution app icon integration.
- **Custom Accent Colors & Glass Materials**: True Black (OLED), Frosted Dark, Neon Cyber, and Ultra Thin.
- **Floating Island Mode**: Customizable top margin and corner rounding for external monitors.
